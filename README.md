vMix Helper

Is an open source, swiss knife set of tools written in python to help using vMix specially in live production environment.

1- Unlimted full screens instead of the limited 2 vMix give you.

2- Fixing limited vMix Hotkey capability.
  - Sending Hotkeys to vMix even if its in the background or not in focus.
  - Support of Alt or ctrl key combinations.
  - Send the hotkey to input layer.
  - Hotkey modifier, lets you get extra functionality from your clicker.

3- Provide a workaround for PowerPoint input, Helpful if you have animation or video in your PowerPoint file.

4- Change of input layers live in a single click.

5- Extra options on recording or streaming.

6- PDF converter to use as pictures input.

7- Video/Audio downloader from popular sites, To use in your production.

8- Add Gstreamer support.

9- Recive files on the computer.
